# 自动补全

`webgal-language-service` 为 WebGAL 脚本提供了上下文感知的自动补全功能。编写脚本时，服务会根据当前输入位置和已有内容，实时提示可能的语句元素。本文档说明补全的触发规则、各位置的提示行为，以及所支持的数据类型。

## 触发

一条 WebGAL 语句通常由以下几部分组成：

```
语句类型:主参数 -参数名=参数值 ; 注释
```

服务监听特定字符的输入来判断当前所在位置，并给出对应的补全列表：

| 输入字符   | 触发位置           | 提供的补全                                   |
| ---------- | ------------------ | -------------------------------------------- |
| 行首非空白 | 语句类型           | 语句类型、对话人物名、语句模板               |
| `:`        | 主参数             | 资源路径、枚举、标识符、JSON 等              |
| `-`        | 参数名             | 可用参数名，部分附带值模板，已用参数自动排除 |
| `=`        | 参数值             | 枚举项、标识符、文件路径、JSON 结构等        |
| `/` `\`    | 资源路径或立绘动作 | 文件目录分层浏览，立绘专属动作/表情列表      |
| `"`        | JSON 字符串        | JSON 键名与结构                              |

### 语句类型

在行首或语句类型部分输入时，补全会同时涵盖三类内容：

1. **语句类型提示**  
   列出所有可用的语句类型（如 `changeBg`、`setTransform`）。  
   - 需要主参数的语句类型，生成 `语句类型:|`，光标跳至主参数位置；  
   - 不需要主参数的语句类型，直接生成 `语句类型;`。

2. **对话人物名**  
   项目中收集到的对话人物名称也会出现在补全列表中。选择后自动插入 `人物名:`，方便直接书写台词。这是对 `say` 语句语法糖的快捷输入支持。

3. **语句模板**  
   内置了一些常见写法的快速片段，以 `语句类型.特征` 的形式显示。选择后将展开为带占位符的完整样板，支持按 <kbd>Tab</kbd> 跳转填充。  
   例如 `changeFigure.motion` → `changeFigure:| -id=| -motion=| -next|;`

### 参数名

输入 `-` 时，服务会列出当前语句所有可用的参数名。补全具有以下特点：

- **区分普通参数与布尔参数**  
  需要参数值的参数生成 `-参数名=` 的补全；布尔参数仅插入 `-参数名`，不附带等号。

- **已用参数自动过滤**  
  当前语句中已经出现的参数不会再次列入补全，避免重复添加。

- **值模板自动展开**  
  部分参数在补全时附带了预设的值格式。例如 `intro` 语句的 `-fontColor` 会展开为 `-fontColor=rgba($1,$2,$3,$4)`，引导用户填写颜色分量。

- **特殊混合补全**  
  少数参数在补全名称的同时，也会直接提供文件系统的选项。例如在 `say` 语句中输入 `-vocal` 参数时，除了插入 `-vocal=`，还会列出 `vocal` 目录下的语音文件路径，选择后即完成值填写。

### 主参数 / 参数值

主参数和参数值的补全内容由语句类型和具体参数决定，具体的数据来源和补全方式见[补全类型](#补全类型)一章。

## 补全类型

根据不同语义，补全内容分为以下几类，服务会根据上下文自动选择合适的策略。

### 静态枚举

对于取值限定在少数预定义选项内的参数，直接列出所有可能值。覆盖的参数包括：

- `fontSize` — 字体大小（`small`、`medium`、`large`），用于 `say` 和 `intro`
- `ease` — 缓动类型（`linear`、`easeIn`、`easeOut`、`circIn`、`backOut` 等）
- `pixiPerform` 主参数 — 特效种类（`snow`、`heavySnow`、`rain`、`cherryBlossoms`）
- `setComplexAnimation` 主参数 — 复杂动画（`universalSoftIn`、`universalSoftOut`）
- `setTextbox` 主参数 — 文本框显隐（`on`、`hide`）
- `filmMode` 主参数 — 电影模式开关（`enable`、`none`）
- `intro` 的 `animation` 参数 — 全屏文字动画（`fadeIn`、`slideIn`、`typingEffect` 等）

### 动画名称

`enter`、`exit` 和 `setAnimation` 所需的值并非固定枚举，而是根据项目 `animation` 目录下的 JSON 文件动态提取。每个动画文件的文件名（去除 `.json` 后缀）即为可选值。因此，补全列表会随着项目动画资源的增删而变化。

### 标识符收集

服务在加载项目时会解析所有场景文件，收集特定类型的标识符，并在以下参数位置提供补全。收集的标识符会根据使用频次排序。

| 标识符类型 | 收集对象                         | 用于                                                         |
| ---------- | -------------------------------- | ------------------------------------------------------------ |
| 对象 ID    | 所有 `id` 参数的值               | `-id`、`-target` 等                                          |
| 对话人物   | `say` 语句和 `-speaker` 参数的值 | `-speaker` 及语句类型快捷输入                                |
| 标签       | `label` 语句的主参数             | `jumpLabel` 主参数、`choose` 跳转目标                        |
| 鉴赏系列   | `-series` 参数的值               | `unlockCg`、`unlockBgm` 的 `-series`                         |
| 时长       | 所有以毫秒为单位的数值           | `-duration`、`-enterDuration`、`-delayTime`、`wait` 主参数等 |

### 资源路径

所有需要指定项目内文件的位置（背景、立绘、音乐、音效、视频、场景文件、图片立绘的部件等）都支持按目录分层补全。输入路径分隔符（`/` 或 `\`）后，服务会列出当前目录下的子文件夹与文件。选择文件夹后自动追加分隔符，可继续深入。

### 立绘动作与表情

对于 Live2D 或 Spine 类型的立绘，其动作和表情文件存放在立绘资源自身的子目录中。当 `changeFigure` 语句通过主参数或 `-id` 指定了具体立绘后，后续的 `-motion` 和 `-expression` 参数值补全会自动切换到该立绘对应的动作/表情目录，列出该角色专属的选项。若立绘未指定，则此补全暂不生效。

### JSON 结构

部分参数期望填入 JSON 格式的数据。服务内嵌了基于 Schema 的宽松 JSON 补全支持，可以提示键名并辅助闭合结构。当前支持 JSON 补全的位置包括：

- `transform` — `setTransform` 的主参数，`changeBg` / `changeFigure` 的 `-transform` 参数
- `tempAnimation` — `setTempAnimation` 的主参数
- `blink` — `changeFigure` 的 `-blink` 参数（Live2D 眨眼数据）
- `focus` — `changeFigure` 的 `-focus` 参数（Live2D 注视数据）

在这些位置输入 `{"` 后，会触发键名提示，并尝试补全对应的 JSON 片段。

## 注释补全

在分号后的注释区域，输入 `nolint` 可启动诊断抑制配置的补全。选择 `nolint:` 后会进一步提示所有可用的诊断码（如 `WG001` 至 `WG016`），多个诊断码用 `|` 分隔。
