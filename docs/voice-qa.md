# 配音工作流手动验收清单

本清单用于在真实环境中验证 GPT-SoVITS 配音工作流。自动化测试覆盖了「场景解析 / 语句改写 / 音频裁剪 / 内容哈希 / 角色库与 zip / 记录对齐 / 队列调度 / 选项卡顺序」等纯逻辑（见 `cargo test -p webgal-ink`、`cargo test -p webgal-language-core` 与 `npx vitest run`），但以下环节依赖真实 GUI、真实整合包与真实网络端口，必须手动走一遍。

## 0. 前置条件

- 一份 GPT-SoVITS **v4** 整合包（含 `api_v2.py`、`runtime\python.exe` 与 v4 权重）。
- 一个 WebGAL 项目（含 `game/scene/*.txt` 与 `game/vocal/`）。
- 一段 3~10 秒、人声清晰的参考音频（wav）。

## 1. 自动化验证

```bash
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
npm run lint
cd editor && npx tsc --noEmit && npx vitest run && npx vite build
```

预期：全部通过，无 warning。

## 2. GSOV 进程管理

| 步骤                                 | 预期                                                                                      |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| 配音工作台选择整合包目录             | 自动填充启动方式为「整合包内置运行时」，路径为 `<root>\runtime\python.exe`，端口 9880     |
| 点「启动服务」                       | 工作台页头与底部状态栏变为「启动中…」，日志出现 `$ <python> -I api_v2.py ...` 与模型加载输出 |
| **启动过程中**                       | 「停止服务」按钮**仍可点击**（首次加载模型要几十秒，路径填错时要能立刻停下）               |
| 等待模型加载完成                     | 状态变为「就绪」，工作台队列区可用                                                        |
| 切换「启动方式 / 合成设置」两页       | 默认语言在「合成设置」页；「启动方式」页只有整合包目录、启动方式与对应的解释器/命令         |
| 启动方式页                           | **没有**绑定地址、端口、控制脚本、推理配置以外的多余字段                                   |
| 选「整合包内置运行时」               | 第二项是**只读**的解释器路径（由整合包决定，不可编辑）                                     |
| 选「conda 环境」                     | 第二项变成环境下拉，**没有**文件夹图标；下拉里能列出本机 conda 环境                        |
| 选「外部 Python」                    | 第二项是解释器路径，右侧有文件夹图标                                                       |
| 选「自定义命令」                     | 第二项是**一整条命令**输入框（不再单开参数框），**没有**文件夹图标                          |
| 整合包目录右侧的文件夹按钮            | 未选过时点击弹出目录选择；已选过时点击在文件管理器中打开（只有一个按钮）                   |
| 切到「外部 Python」并指向 conda 环境 | 启动参数**不含** `-I`（否则会因屏蔽用户级 site-packages 而 `ModuleNotFoundError: click`） |
| 切到「自定义命令」                   | 命令原样执行，Ink 不追加任何参数                                                          |
| 点「停止服务」                       | 进程优雅退出（服务端有机会落盘 `tts_infer.yaml`），状态回到「未启动」                     |
| 退出 Ink                             | GSOV 进程一并退出，无残留 `python.exe`                                                    |
| 两栏卡片内展开语言/模型下拉          | 弹层**不被卡片底边切掉**：下方空间不足时朝上展开，并按可用空间限高滚动                     |
| 关闭下拉                             | 点击别处或按 `Esc` 都能关闭                                                               |

> 端口被占用时应给出可读错误，而不是静默卡在「启动中…」。

## 3. 角色库

| 步骤                   | 预期                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| 新建角色               | 出现在列表中，id 为名称的 slug（中文保留）                       |
| 角色库工具栏           | 只有「搜索 / 选择角色 / 新建角色」，**没有**导入按钮             |
| 角色卡                 | 只有「角色名 / 角色 ID / GSOV 模型下拉 / 描述 / 参考音频 / 删除角色」 |
| 角色卡                 | **没有**「默认语言」字段，**没有**「别名」字段，**没有**权重路径输入框 |
| 「删除角色」按钮       | 红色（危险样式）                                                 |
| 编辑第一个角色的任意设置 | 卡片**不会**换位置（列表按星标与加入顺序排列）                 |
| 编辑角色 ID            | 保存成功；若与已有角色冲突则报错并回滚显示                       |
| 添加 4 秒参考音频      | 直接入库，记录时长/采样率，内容哈希文件名 `ref_<hash>.wav`       |
| 添加 2 秒参考音频      | **静默**在尾部补静音，入库后时长 ≥ 3s                            |
| 添加 12 秒参考音频     | 弹出裁剪对话框：显示波形、自动放置区间、可拖拽、可试听           |
| 裁剪区间拖到 > 10s     | 确认按钮禁用并提示超限                                           |
| 参考文本留空           | 确认按钮禁用（v4 必需）                                          |
| 再次添加同一文件       | 复用同一 `ref_<hash>.wav`，不产生副本                            |
| 试听                   | 与角色列表的试听互斥（同时只有一个在响）                         |
| 导出 zip               | 压缩包含 `character.json` 与 `audio/ref_*.wav`，**不含**模型选择 |
| 导入 zip（另建角色名） | 角色入库，参考音频落盘，模型选择为空                             |
| 删除参考音频           | 文件被删除；若库内其他条目引用同一文件则不删                     |
| 删除角色               | 配置与音频目录一并删除                                           |

## 3.1 选择角色对话框

**核心约定：对话框尺寸固定，不随内容自动缩放。**

| 步骤                       | 预期                                                                       |
| -------------------------- | -------------------------------------------------------------------------- |
| 打开「选择角色」           | 面板尺寸固定（880×600），角色多少都不改变外框大小                           |
| 角色很多时                 | 只有中间的角色区滚动；标题栏与底部按钮位置不动                              |
| 顶部工具栏                 | 搜索 + 「导入角色」+「从清单导入」在**同一行**，不换行、不挤成两行           |
| 点「导入角色」             | 选择 zip 并导入，列表立即出现新角色                                        |
| 点「从清单导入」           | 依次选择文本清单目录（含 `.list`）与音频目录；完成后提示导入条数与角色数     |
| 「从清单导入」取消第二次选择 | 不产生任何导入，列表保持不变                                              |
| 点某个角色名               | 打开参考音频对话框，可添加/删除/试听                                       |
| 按 `Esc`                   | 关闭当前对话框                                                             |

## 4. 配音编辑模式

**核心约定：未打开配音工作台时，界面上不应出现任何配音痕迹。**

| 步骤                           | 预期                                                               |
| ------------------------------ | ------------------------------------------------------------------ |
| 未打开配音工作台               | 场景选项卡上**没有**麦克风按钮（无论是否选中）                     |
| 打开配音工作台                 | **没有任何**场景卡被自动切成配音卡，也没有麦克风                    |
| 点一张场景卡                   | 只有这张卡出现**划线麦克风**；其它场景卡没有                        |
| 切到另一张场景卡               | 麦克风跟着当前卡走；**不会**因为"切过去"就变成配音卡                |
| 切到工作台/说明页              | 原来那张卡上的**划线麦克风消失**                                    |
| 点当前场景卡的麦克风（划线）   | 该卡立刻变成配音卡（实心麦克风），编辑器切为只读配音卡              |
| 再点这张配音卡的麦克风（实心） | 立刻切回**普通场景卡**（不需要切走再切回来）                        |
| 开着配音卡时切到别的场景卡     | 那张卡是普通场景卡；原来那张配音卡仍显示实心麦克风（可随时点回去退出） |
| 关闭配音工作台                 | 全部场景退出配音编辑模式，所有麦克风按钮消失                       |
| 打开/关闭麦克风按钮            | 选项卡宽度不变（槽位固定占位，标题不会左右跳动）                   |
| 纯文本标题的选项卡（工作台等） | 标题前**没有**多余留白；所有选项卡图标落在同一条竖线上             |
| 光标点到对话行                 | 操作台显示**这一行**的对话；点到上一行/下一行不会串到别的对话       |
| 光标移到非对话行               | 操作台清空为提示文字，**高度不变**（编辑器不跳动）                 |
| 光标停在没写分号的对话行上     | 仍识别为**该行**的对话（不再命中上一条）                           |
| 选中某句对话                   | 编辑器里**整条对话**整行高亮                                       |
| 尝试在配音编辑卡里输入/粘贴    | **无法编辑**（只读）：没有插入符、不触发自动保存、没有 git 行差异   |
| 语句操作台默认状态             | **不出现滚动条**（一屏放得下）；展开「高级设置」后才滚动            |

## 4.1 配音工作台是普通选项卡

| 步骤                 | 预期                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| 点击顶栏配音按钮     | 打开（或聚焦）「配音工作台」选项卡，与场景卡在同一条选项卡栏里             |
| 页面结构             | 页头（标题 + 服务状态 + 启动/停止 + 帮助）；下一行左「启动方式 / 合成设置」、右「队列 / 日志」；底部角色库占满剩余高度 |
| 拖拽该选项卡         | 与其它选项卡行为一致（可任意位置、可中键关闭）                             |
| 「启动服务」与「帮助」两个按钮 | 宽度**各自按内容取**（不强制等宽，短标签不被撑出多余留白）        |
| 在两栏的「启动方式 / 合成设置」之间切换 | **下方角色库高度不变**（两栏高度固定，不随内容自动缩放）    |
| 右栏「队列」页       | 提供「清理缓存音频」与「清空已完成任务」两个图标按钮                       |
| 右栏「日志」页       | 那两个按钮**消失**，改为「导出日志」按钮                                   |
| 点「导出日志」       | 弹出保存对话框，导出为文本文件                                             |
| 队列有任务时         | 状态栏显示 `· 队列 N`                                                      |
| 关闭该选项卡         | 退出配音功能，其它选项卡保持原样                                           |

## 4.3 选项卡栏（全类型统一）

所有选项卡（场景/文件、文本预处理、差异比较、使用说明、**配音工作台**）共用同一套控件：

| 步骤           | 预期                                                       |
| -------------- | ---------------------------------------------------------- |
| 拖拽任意选项卡 | 可以拖到**任意位置**，不受种类限制（不同类型可以交错排布） |
| 拖到最右端     | 插入竖线画在**最右端**，不是最后一个选项卡的左侧           |
| 打开新选项卡   | 插入在**当前选项卡之后**（而非按种类追加到某一段）         |
| 关闭活动选项卡 | 激活它**右侧**的邻居；右侧没有则回退到左侧                 |
| 中键点击选项卡 | 等同于点关闭按钮                                           |
| 任意时刻       | **只有一个**选项卡处于选中态（不会出现两个同时高亮）       |
| 各类型选项卡   | 图标都正常显示（预处理、差异比较、配音工作台都有图标）     |
| 带图标与不带图标的选项卡相邻 | 标题起始位置对齐，无图标项不留空隙、有图标项不贴边 |

### 4.4 提示文本风格

全项目的悬浮提示统一使用原生 `title` 属性（与选项卡的关闭按钮一致），**不使用** Fluent UI 的 `Tooltip` 组件（其在 WebView 中会出现背景透明的渲染问题）。检查点：悬浮麦克风按钮、选项卡角标、配音记录右键项、参考音频按钮时，提示都是系统原生样式，且不会有“背景被置空”的现象。

### 4.5 使用说明页滚动

打开使用说明页并快速滚动到底部再回到顶部，应保持流畅：说明文档只在挂载时渲染一次（React 不再重建该子树），解析结果在模块级缓存。

### 4.6 下拉选择器

配音流程里所有下拉（启动方式、默认语言、角色默认语言、角色模型）都是**自绘下拉**，不使用 Fluent UI 的 `Dropdown`。

| 步骤                     | 预期                                                                   |
| ------------------------ | ---------------------------------------------------------------------- |
| 点击任意下拉             | 就地展开选项面板，**整个窗口不会白掉**，再点一下也不会"恢复"             |
| 逐项点开所有下拉         | 无一例外（工作台、角色卡、语句操作台、裁剪对话框都要检查）             |
| 靠近卡片底部的下拉       | 下方空间不足时朝**上**展开，不被卡片底边切掉                             |
| 列表里靠底部的角色卡下拉 | 朝上朝下都放不下时先把列表滚动一点腾出空间，弹层仍完整可见               |
| 选项很多时               | 面板按可用空间限高并内部滚动                                             |
| 选择一项                 | 面板关闭，值已生效并持久化                                               |
| 点击别处 / 按 `Esc`      | 面板关闭，不改变当前值                                                   |

| 步骤                   | 预期                                                               |
| ---------------------- | ------------------------------------------------------------------ |
| 点「测试 x4」          | 任务进入立即队列；记录区新增一条「测试 x4」并自动选中；显示进度    |
| 生成中再点「生成 x32」 | 进入普通队列；当前测试任务不被中断，测试优先于生成                 |
| 连续点 3 次测试        | 三条任务同角色连续执行（日志中参考音频缓存命中，不再重载）         |
| 生成中观察配音工作台   | 待处理/运行中计数正确，显示估算剩余时间                            |
| 等待完成               | 记录项变为已完成，可试听；音频落盘于 `<appdata>\tts\<hash>.wav`    |
| 修改温度后再点「生成」 | 创建**新任务**；旧记录不受影响；应用按钮禁用并提示「当前为新配置」 |

## 8. 已知边界

- **仅本地部署**：参考音频与权重路径必须是 GSOV 进程所在机器的本地路径，API 没有上传通道。容器部署需要自行把项目目录与 `<appdata>` 挂进容器。
- **仅 v4 模型**：采样步数固定为测试 x4 / 生成 x32，界面不暴露；`super_sampling` 在 v4 上无效，界面不暴露。
- **文本不切分**：一句对话整体合成，不提供切分方式选择。
- **缓存不自动清理**：为避免误删跨场景引用的文件，只提供手动确认清理。
